About

{{ page.title }}

The internet today is bloated. Open almost any basic website — even one that's just text, like a devotional hymn or a recipe — and you'll wade through ad networks, tracking scripts, auto-playing video, and megabytes of JavaScript before you ever see the content you came for. It's annoying on a fast connection. On a slow one, or on a mid-tier phone, it can make a page genuinely unusable.

स्तोत्रसुधामंजिरी exists because this didn't have to be the case. It's a static site: no ad network, no analytics trackers beyond a single cookie-free visit counter, no build step most visitors ever notice, no framework doing work it doesn't need to do. Every page is a few kilobytes of plain HTML and CSS. It works offline once visited, installs as a PWA if you want it to, and loads instantly even on a bad connection.

It's also built to be extended rather than rebuilt. Adding a new shloka or a new devata is a matter of dropping in a plain-text file with a few lines of front matter — no database, no admin panel, no build pipeline to fight. The whole site is open on GitHub.
